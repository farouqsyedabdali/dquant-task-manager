# Tialz Client

React/Vite frontend for the Tialz task manager.

## Scripts

```bash
npm run dev
npm run lint
npm test
npm run build
npm run preview
```

## Environment

Copy `.env.example` to `.env` and set:

```env
VITE_API_URL="http://localhost:3000/api"
```

Mockup and test-only routes are available in Vite dev mode only.
